## 个股分析框架

### 分析维度
1. **基本面**: PE/PB/ROE/营收增长/利润增长
2. **技术面**: 趋势/动量/波动率/成交量
3. **资金面**: 主力净流入/换手率/大单比例
4. **情绪面**: 市场情绪/板块热度/概念关联

### 评分规则
- 各维度独立评分 (-1.0 ~ 1.0)
- 加权综合: 基本面30% + 技术面25% + 资金面25% + 情绪面20%
- 综合 > 0.5: 推荐
- 综合 < -0.5: 不推荐
- 其他: 观望

### 风险检查
- PE > 100 或 < 0: 标记异常
- 连续3日下跌且无利好: 标记风险
- ST/*ST 股票: 直接排除
