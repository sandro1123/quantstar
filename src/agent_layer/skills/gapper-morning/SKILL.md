# 开盘 Gap 交易框架

## 分析步骤
1. 检查竞价情况
   - 竞价成交价 vs 前日收盘: 跳空方向 + 幅度
   - 竞价成交量: 放量跳空 vs 缩量跳空
   - 竞价未匹配量: 买盘多则看涨, 卖盘多则看跌

2. 板块共振检查
   - 所属板块指数开盘情况
   - 板块内是否有其他股票同步跳空
   - 板块热度: 近期热点板块 vs 冷门板块

3. 前5日资金流向
   - 主力资金是否持续流入
   - 北向资金是否配合

## 决策规则
- 跳空 2-5% + 放量 50%+ + 板块共振 → 强势追击
- 跳空 5%+ + 缩量 → 警惕高开低走
- 跳空 < 2% + 放量 → 正常交易, 观望
- 跳空向下 > 3% + 放量 → 恐慌性下跌, 不抄底
