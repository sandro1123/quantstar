# CANSLIM 筛选法

## 分析步骤
- C: 当季每股收益同比增长 > 25%
- A: 年度每股收益增长率 > 25%, 连续3年
- N: 新产品/新管理层/新高价
- S: 供给与需求: 流通盘适中, 机构增持
- L: 行业龙头或龙头地位
- I: 机构认同度: 机构投资者增持
- M: 市场方向: 大盘趋势向上

## 决策规则
- 满足 C+A+L+I → 重点关注
- 满足 C+A+N → 加入观察
- 不满足 C+A → 跳过
- 市场方向向下 → 整体观望
